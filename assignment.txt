Don't use React yet. Don't use TypeScript yet. Don't use an API yet.

Get comfortable writing vanilla JS first.

And for each project, I'd recommend you try it yourself first without looking at a solution. Since you've already learned the programming logic through Python, the main thing you're building now is your ability to think in JavaScript syntax and JS methods.
